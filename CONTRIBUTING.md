# Contributing to Voting Platform\n\nThank you for your interest in contributing! Please follow these guidelines.\n\n## Code of Conduct\n\nBe respectful, inclusive, and professional in all interactions.\n\n## Getting Started\n\n1. Fork the repository\n2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/voting-platform.git`\n3. Create a feature branch: `git checkout -b feature/your-feature-name`\n4. Install dependencies: `npm install`\n\n## Development Guidelines\n\n### Code Style\n- Use TypeScript for all new code\n- Follow ESLint configuration\n- Use Prettier for code formatting\n\n### Commit Messages\n- Use clear, descriptive commit messages\n- Start with a verb: \"Add\", \"Fix\", \"Update\", etc.\n- Example: `Add AI recommendation feature`\n\n### Pull Requests\n1. Ensure tests pass: `npm run test`\n2. Build the project: `npm run build`\n3. Provide a clear description of changes\n4. Reference related issues\n\n### Testing\n- Write tests for new features\n- Maintain or improve test coverage\n- Run `npm run test:coverage` before submitting\n\n## Reporting Issues\n\n1. Check existing issues first\n2. Provide a clear title and description\n3. Include steps to reproduce\n4. Add relevant screenshots or logs\n\n## Questions?\n\nOpen an issue or contact: atotura.rasheed@adwumatech.ai\n\nThank you for contributing! 🚀\n
